# 스플렌더 온라인 (초안)

보드게임 **스플렌더(Splendor)** 의 웹 멀티플레이어 구현 초안입니다.
호스트가 방을 만들고 방 코드를 공유하면 게스트가 입장하여 2~4인이 함께 플레이합니다.
**1인용 모드**: 홈 화면의 "혼자 하기"를 누르면 AI 봇과 대전할 수 있습니다
(대기실에서 봇을 최대 3개까지 추가/제거 가능, 사람+봇 혼합도 가능).

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.
같은 네트워크의 다른 사람(휴대폰 포함)은 `http://<호스트IP>:3000` 으로 접속하면 됩니다.
접속 가능한 LAN 주소는 서버 시작 로그와 대기실 화면에 표시됩니다.

- PC·태블릿·휴대폰 모두 지원 (가변 해상도 — 화면 폭에 맞춰 카드/토큰이 축소됨)
- 휴대폰 접속이 안 되면 Windows 방화벽에서 Node.js의 사설 네트워크 인바운드를 허용하세요.

## 구현된 규칙 (나무위키 기준)

- 보석 5종(다이아몬드·사파이어·에메랄드·루비·줄마노) + 황금(조커) 토큰
  - 인원별 보석 토큰: 2인 4개 / 3인 5개 / 4인 7개, 황금은 항상 5개
- 개발 카드 90장 (1단계 40장 / 2단계 30장 / 3단계 20장, 각 단계 4장 공개)
- 귀족 타일 10종 중 인원수+1개 사용, 조건 충족 시 자동 방문(+3점, 턴당 1명, 동시 충족 시 선택)
- 턴 행동 (셋 중 하나)
  1. **토큰 가져오기**: 서로 다른 색 3개, 또는 같은 색 2개(은행에 4개 이상일 때)
  2. **카드 구매**: 공개 카드 또는 내가 예약한 카드. 보너스 할인 + 황금 조커 지불
  3. **예약(킵)**: 공개 카드 또는 더미 맨 위(비공개). 최대 3장, 황금 토큰 1개 획득
- 토큰 소지 한도 10개 — 초과분은 즉시 반납
- 15점 달성 시 그 라운드를 마지막까지 진행 후 종료
- 동점 처리: 개발 카드 수 적은 쪽 → 귀족 많은 쪽 → 남은 토큰 많은 쪽 → 후공 승리

## 시작 전 규칙 정하기 (대기실, 호스트만)

| 규칙 | 기본값 | 범위 |
|------|--------|------|
| 턴 제한시간 | 30초 | 10~60초 (10/15/20/30/45/60) |
| 목표 점수 | 15점 | 10~20점 |
| 선 플레이어 | 차례대로 | 차례대로 / 랜덤 |
| 봇 난이도 | 보통 | 쉬움 / 보통 / 어려움 |
| 예약(킵) 한도 | 3장 | 금지(0)~5장 |
| 귀족 타일 수 | 기본(인원+1) | 없음(0)~5개 |

- 제한시간이 지나면 자동 처리됩니다: 일반 턴은 패스, 토큰 반납·귀족 선택은 자동 선택.
  남은 시간은 게임 화면 상단에 카운트다운으로 표시됩니다.
- "차례대로"는 입장 순서(재대결 시 한 칸씩 로테이션), "랜덤"은 매 게임 순서를 섞습니다.

## 봇 AI

서버(`game/ai.js`)에서 봇 차례에 자동으로 행동을 결정합니다. 난이도 3단계:

- **쉬움**: 무작위 위주 — 살 수 있으면 아무 카드나 구매(70%), 토큰도 무작위로 수집
- **보통**: 살 수 있는 최고점 카드 구매 → 부족 토큰이 가장 적은 목표 카드용 토큰 수집
  → 토큰이 한도에 가까우면 예약으로 황금 확보
- **어려움**: 보통 + 점수·귀족 기여도로 목표를 고르고, 귀족 즉시 달성을 노리며, 더 일찍 예약

자체 대전 100판 기준 승률: 보통 vs 쉬움 96%, 어려움 vs 보통 64%.
소지 한도 초과 반납, 귀족 선택도 난이도와 무관하게 자동 처리됩니다.

## 재대결

게임 종료 화면에서 호스트가 **재대결**을 누르면 같은 멤버로 새 게임이 시작됩니다.
(선 플레이어는 매판 로테이션)

## 구조

```
server.js          # Express + Socket.IO 서버, 방/봇 관리, 재대결
game/cards.js      # 개발 카드 90장 + 귀족 10종 데이터
game/game.js       # 게임 상태/규칙 로직 (서버 권위)
game/ai.js         # 봇 행동 결정 (1인용 모드)
public/index.html  # 화면 (홈 / 대기실 / 게임)
public/style.css
public/client.js   # 렌더링 + 입력 처리
```

포트 변경: `node server.js 3210` 처럼 인자로 지정하거나 `PORT` 환경변수 사용.
